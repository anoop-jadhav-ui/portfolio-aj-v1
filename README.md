## Setup and Commands

Use the following commands to work with this project:

```bash
# Install dependencies
$ npm install

# Run the development server
$ npm run dev

# Build for production
$ npm run build

# Run the production server
$ npm run start

# Run unit tests with coverage
$ npm run coverage
```
